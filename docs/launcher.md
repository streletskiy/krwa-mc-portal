# Вход через лаунчер

1. Установите публичный HTTPS-адрес сайта в админке. Игроки должны иметь возможность открыть его с того устройства, на котором запускают игру.
2. Создайте аккаунт и проверьте персонажа в личном кабинете. При регистрации портал создаёт профиль Minecraft.
3. В лаунчере с поддержкой authlib-injector добавьте адрес `https://portal.example.org/api/yggdrasil`. Лаунчеры с поддержкой ALI также принимают корень сайта и находят API по заголовку `X-Authlib-Injector-API-Location`.
4. Войдите с аккаунтом портала и выберите персонажа. Для сервера с authlib-injector используйте тот же API и включённую проверку сессий.

```sh
curl -fsS -D - -o /dev/null https://portal.example.org/
curl -fsS https://portal.example.org/api/yggdrasil
```

Метаданные содержат имя сервера, разрешённые домены текстур и открытый ключ подписи. Обновление образа должно сохранять том с базой и ключами. [Протокол и параметры подключения](en/guide/yggdrasil-api.md).
