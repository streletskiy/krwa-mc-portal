# Установка и оформление

## Локальный запуск

Понадобятся Docker Engine с Compose и Git.

```sh
git clone https://github.com/streletskiy/krwa-mc-portal.git
cd krwa-mc-portal
cp .env.example .env
docker compose pull
docker compose up -d
```

В PowerShell для копирования используйте `Copy-Item .env.example .env`. Откройте [локальную установку](http://localhost:3000/init), создайте первого администратора и укажите адрес, который будет доступен игрокам. Состояние готовности возвращает `/health/ready`.

## Публичный сайт

Завершите первичную настройку через доверенный локальный доступ. Направьте HTTPS reverse proxy на порт привязки Compose, укажите внешний адрес в настройках сайта и задайте `PORTAL_HTTP_COOKIES=false`. После изменения `.env` выполните `docker compose up -d`.

SQLite, ключи подписи, настройки и загруженные текстуры хранятся в томе `portal-data`, смонтированном в `/data`. Для резервной копии штатно остановите сервис, скопируйте весь том и снова запустите портал. При использовании S3 сохраните также соответствующие объекты. [Конфигурация хранилища](en/deployment/docker.md).

## Оформление

Название, описание, иконку и логотипы можно менять в админке. Непустые значения переменных окружения имеют приоритет. Для картинок используйте публичные HTTPS-адреса или пути от корня сайта. Для локальных ресурсов можно смонтировать каталог с изображениями только для чтения в `/frontend-override/static/brand` и ссылаться на `/static/brand/имя-файла`.

| Переменная | Назначение |
|---|---|
| `PORTAL_TITLE`, `PORTAL_DESCRIPTION` | Название сайта и описание для превью ссылки |
| `PORTAL_FAVICON_URL` | Иконка сайта и установленного веб-приложения |
| `PORTAL_WORDMARK_DARK_URL`, `PORTAL_WORDMARK_LIGHT_URL` | Логотип для тёмной темы и логотип для светлой темы |
| `PORTAL_HERO_URL`, `PORTAL_SOCIAL_IMAGE_URL` | Иллюстрация на главной и картинка для превью ссылки. Для превью лучше указать абсолютный HTTPS-адрес |
| `PORTAL_PORT` | Локальный порт, по умолчанию 3000 |
| `PORTAL_IMAGE` | Полное имя образа, включая тег или digest |

## Необязательные сервисы

Пустое значение скрывает соответствующий раздел.

| Переменная | Что должен обслуживать ваш сервер |
|---|---|
| `PORTAL_DOWNLOAD_BASE` | Каталог ссылок на сборки лаунчера. Портал добавляет к базе `/windows`, `/linux`, `/linux-deb`, `/linux-arch` и `/macos` |
| `PORTAL_COMMUNITY_URL` | Публичный JSON со списком серверов и статусами. При размещении на другом домене разрешите CORS для адреса портала |
| `PORTAL_WORLD_ADMIN_URL` | Страница администрирования офлайн-миров в вашем дополнительном сервисе. Сервис должен самостоятельно проверять права администратора |

Минимальный ответ каталога серверов:

```json
{"updatedAt":"2026-01-01T12:00:00Z","servers":[{"id":"survival","name":"Survival","description":"Совместное выживание","minecraftVersion":"1.21.1","packVersion":"1.0","mods":[],"status":{"state":"online","online":2,"max":20}}],"downloads":[]}
```
